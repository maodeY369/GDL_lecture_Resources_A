# 中文翻译风格指南

- 使用严谨、自然的简体中文学术表达；保留原句的条件、否定、量词、因果、模态强度和例外。
- `domain` 统一译为“域”，`invariance/equivariance` 统一译为“不变性/等变性”，`gauge` 在几何语境中译为“规范”。
- 原文只写缩写时保持缩写；原文给出全称与缩写时翻译全称并保留缩写，例如“卷积神经网络（CNN）”。
- 模型、数据集、软件、库、文件格式、程序标识符和品牌化名称保持英文，具体以 `keep-original.txt` 为准。
- 中文正文使用中文标点；数学、代码、路径、URL、labels、citation keys 和 LaTeX 命令内部保持 ASCII 形式。
- 不翻译任何数学模式内容，包括数学内部的 `\text`、`\mathrm`、`\operatorname` 等；这类自然语言只登记审查。
- 保持段落、环境、标签、引用、图像路径和公式换行，不进行与翻译无关的重构。
- 图注中的方向词翻译为“上/下/左/右”；模型名与 citation 命令保持原样。
